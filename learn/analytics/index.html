Аналитика: продвинутые приёмы

1.Топ-N в каждой группе

Самый частый вопрос на собеседовании. Схема: ROW_NUMBER() OVER (PARTITION BY группа ORDER BY метрика DESC) в CTE, снаружи WHERE rn <= N. Та же схема с ORDER BY дата DESC и rn = 1 даёт «последнюю запись в группе».

WITH ranked AS (SELECT visitor_id, id, order_date, ROW_NUMBER() OVER (PARTITION BY visitor_id ORDER BY order_date DESC, id DESC) AS rn FROM orders) SELECT visitor_id, id, order_date FROM ranked WHERE rn = 1 LIMIT 8

2.Условная агрегация (сводная таблица)

SUM(CASE WHEN условие THEN значение ELSE 0 END) — каждый такой столбец считает только «свои» строки. Так строят сводные таблицы: строки — категории, столбцы — периоды.

SELECT v.city, SUM(CASE WHEN strftime('%m', o.order_date) = '09' THEN o.total ELSE 0 END) AS september, SUM(CASE WHEN strftime('%m', o.order_date) = '10' THEN o.total ELSE 0 END) AS october FROM orders o JOIN visitors v ON v.id = o.visitor_id WHERE v.city IS NOT NULL GROUP BY v.city

3.Пропуски и острова

Как найти серии идущих подряд дней? Если пронумеровать уникальные даты по порядку, то в серии разность julianday(дата) − номер одинакова. Группируя по ней, получаем «острова».

WITH d AS (SELECT DISTINCT order_date AS day FROM orders) SELECT day, ROW_NUMBER() OVER (ORDER BY day) AS n, julianday(day) - ROW_NUMBER() OVER (ORDER BY day) AS island FROM d LIMIT 10

4.Медиана и накопленная доля

В SQLite нет MEDIAN: пронумеруйте значения и возьмите среднее средних строк. Накопленная доля для ABC-анализа: SUM(x) OVER (ORDER BY x DESC) * 100.0 / SUM(x) OVER ().

SELECT id, total, ROUND(SUM(total) OVER (ORDER BY total DESC, id) * 100.0 / SUM(total) OVER (), 1) AS cum_share FROM orders LIMIT 10
