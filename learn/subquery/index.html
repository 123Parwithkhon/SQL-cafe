Подзапросы

1.Скалярный подзапрос

Запрос в скобках, который возвращает одно значение, можно использовать как число.

SELECT name, price FROM teas WHERE price > (SELECT AVG(price) FROM teas)

2.IN и NOT IN

Подзапрос может вернуть список для IN. Ловушка: если в списке есть NULL, NOT IN вернёт пустой результат. Безопаснее NOT EXISTS.

SELECT name FROM teas WHERE id NOT IN (SELECT tea_id FROM order_items)

3.EXISTS и коррелированные подзапросы

Коррелированный подзапрос ссылается на строку внешнего запроса (v.id) и выполняется для каждой строки. EXISTS истинно, если подзапрос вернул хоть одну строку.

SELECT v.name FROM visitors v WHERE EXISTS (SELECT 1 FROM orders o WHERE o.visitor_id = v.id AND o.total > 120)

4.Подзапрос во FROM и в SELECT

Подзапрос во FROM — это временная таблица, к которой можно применить ещё один агрегат. Подзапрос в SELECT считает значение для каждой строки.

SELECT ROUND(AVG(spent), 2) AS avg_spent FROM (SELECT visitor_id, SUM(total) AS spent FROM orders GROUP BY visitor_id)
