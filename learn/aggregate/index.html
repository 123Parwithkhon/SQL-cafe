Агрегация и GROUP BY

1.Агрегатные функции

COUNT, SUM, AVG, MIN, MAX сворачивают много строк в одно значение. COUNT(*) считает строки, а COUNT(столбец) — только значения, которые не NULL.

SELECT COUNT(*) AS all_rows, COUNT(age) AS with_age, COUNT(DISTINCT city) AS cities, ROUND(AVG(age), 1) AS avg_age FROM visitors

2.GROUP BY — по группам

GROUP BY делит строки на группы, и агрегат считается для каждой. В SELECT пишут только столбцы группировки и агрегаты.

SELECT type, COUNT(*) AS teas_count, ROUND(AVG(price), 2) AS avg_price FROM teas GROUP BY type

3.HAVING против WHERE

WHERE фильтрует строки до группировки, HAVING — группы после неё. Условие на COUNT(*) или SUM(...) — всегда в HAVING.

SELECT visitor_id, COUNT(*) AS orders_count, SUM(total) AS spent FROM orders GROUP BY visitor_id HAVING COUNT(*) > 1

4.Порядок выполнения запроса

База выполняет части запроса не в том порядке, в каком они написаны: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT. Поэтому псевдоним из SELECT можно использовать в ORDER BY, но по стандарту нельзя в WHERE.

SELECT strftime('%Y-%m', order_date) AS month, SUM(total) AS revenue FROM orders GROUP BY month ORDER BY revenue DESC
