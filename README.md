# Чайхона SQL

Интерактивный тренажёр SQL на русском и таджикском языках в атмосфере таджикской чайханы.

**Сайт:** https://123parwithkhon.github.io/SQL-cafe/

- 144 задания в 4 уровнях — от `SELECT *` до оконных функций, CTE и аналитики уровня собеседования
- 18 коротких уроков с примерами, которые запускаются прямо в тексте
- Пять учебных баз: «Чайхана» (весь курс), «Бозор» (финальный экзамен) и практикумы «Мактаб» (школа), «Сафар» (автобусы), «Лига» (футбол)
- Подсказки по смыслу ошибки и таблица «не хватает / лишнее»
- Песочница, режим «Собеседование», интервальное повторение
- Звания, «Чайник дня», «Шёлковый путь», светлая и тёмная темы

SQL выполняется прямо в браузере (SQLite, скомпилированный в WebAssembly), поэтому всё работает быстро даже на мобильном интернете.

## Запуск

Нужен Node.js 24+.

```bash
npm install
npm run dev            # http://localhost:3000 — полная версия
npm run build:pages    # статическая сборка для GitHub Pages → out/
```

Публикация на GitHub Pages происходит автоматически при каждом `git push` в ветку `main` (`.github/workflows/deploy-pages.yml`).

Переменные окружения для полной версии — в `.env.example`. Как выложить полную версию с аккаунтами Google и админкой на Vercel — в [DEPLOY.md](DEPLOY.md).
